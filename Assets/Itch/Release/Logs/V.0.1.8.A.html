July 29, 2026
Version 0.1.8.A

Major underlying improvements for web-based platforms, a new app icon, and small bug fixes.

Additions

  • Cells now glow at night! Bioluminescence appearance traits inherit like genetics.
  • Implemented new debugging output and error handling for better maintainability.
  • Revamped environmental system including a basic day/night cycle utilizing time-of-day.

Changes

  • Changed the color of tags within version logs to match new application icon.
  • Made several aesthetic changes to the 'About' menu to refresh the design.
  • The new LifeSim Logo is displayed on the toolbar instead of the game title.
  • Reduced asynchronous thread activity to balance desktop & web performance.

Fixes

  • Addressed an issue where application icons and version were not syncing during build.
  • Identified a bug where environmental settings would not save and load properly.
