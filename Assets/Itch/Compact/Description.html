LifeSim Compact

A modern cellular evolutionary simulator.

Developed by LifeSimulator

LifeSim Compact is an interactive evolutionary sandbox where you watch digital organisms evolve over hundreds of generations. Cells compete for resources, reproduce with genetic variation, and adapt to their environment.

This game is a streamlined experience of LifeSim, with several major features unavailable.

How is it different?

  • Simplified user interface, with only basic player controls available.
  • No session management, analytical, interactive, or application tools included.
  • Automatic session saving and loading every minute, single-save only.

LifeSim Compact is free to download on any platform, and is available to play within a web browser.

"It's got all the simulation, but none of the features."
- LifeSimulator
